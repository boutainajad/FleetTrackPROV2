# 🚛 FleetTrackPRO — Frontend React

Interface React pour gérer les utilisateurs et camions de FleetTrackPRO.
Sprint 3 — Frontend avec ReactJS (composants, JSX, props, useState).

---

## 📦 Installation

```bash
# 1. Cloner le dépôt
git clone <url-du-depot>
cd fleettrack-frontend

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur de développement
npm run dev
